# Park Park Lunch

![Tier](https://img.shields.io/badge/tier-utility-orange)

業務ドライバー向け 昼食候補×停めやすい駐車地点マップ

## これは何？

東京23区の業務ドライバーが、昼休みに「どこで食べるか」「どこに停めるか」を素早く判断できる Web/PWA です。
現在地周辺の飲食店を「停めやすい候補」と「駐車未確認」に分けて表示します。
走行中（10 km/h 以上）は画面操作をロックし、停車後に確認できます。

## こんな時に

- ルート配送中、昼食場所と駐車スポットをまとめて確認したい
- 初めてのエリアで、駐車しやすい飲食店を探したい
- スマホで素早く候補を絞り込んでそのまま移動したい

## 使い方

[デモ（GitHub Pages）](https://165cm.github.io/park-park-lunch/) を開いて位置情報を許可すると、周辺の候補を表示します。

> ⚠️ 現地標識確認必須。本アプリは駐車許可を保証しません。
